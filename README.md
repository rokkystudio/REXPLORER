# REXPLORER

Утилита для быстрого перезапуска Windows Explorer в случае проблем с миниатюрами фотографий и видео, иконками, панелью задач и самим Проводником.

REXPLORER принудительно завершает процессы **Windows Explorer** и восстанавливает ранее открытые папки.

## Что делает

- Сохраняет список реально открытых окон Проводника, относящихся к каталогам файловой системы.
- Принудительно завершает все процессы `explorer.exe`.
- Не запускает `explorer.exe` напрямую.
- После завершения процессов открывает сохранённые каталоги через Shell API. Перезапуск или запуск оболочки выполняет Windows.
- Виртуальные представления («Быстрый доступ», «Этот компьютер», «Домой» и т. п.) намеренно игнорируются.

## Зачем это нужно

- Восстановление «залипших» иконок и миниатюр.
- Перезапуск панели задач и оболочки Explorer.
- Быстрый reset оболочки без выхода из системы и перезагрузки Windows.

## Использование

1. Расположите `REXPLORER.exe` в удобном месте, например на рабочем столе.
2. Завершите операции копирования, перемещения или удаления файлов, выполняемые через Проводник.
3. Запустите `REXPLORER.exe`.
4. Проводник будет принудительно завершён, после чего Windows восстановит оболочку, а REXPLORER откроет сохранённые папки.

> Если перед перезапуском не было открытых папок файловой системы, REXPLORER не открывает дополнительные окна.

## Поддержка

- Windows 10 x86/x64.
- Windows 11 x64.
- Права администратора обычно не требуются.
- В корпоративных или модифицированных конфигурациях автоматический запуск оболочки может быть отключён. В этом случае запустите Проводник вручную: Win+R → `explorer`.

## Ограничения и примечания

- Восстанавливаются только окна с путями файловой системы.
- Виртуальные представления Проводника не восстанавливаются.
- Принудительное завершение `explorer.exe` может прервать операции копирования, перемещения или удаления файлов, выполняемые через Проводник.
- Программа не завершает сторонние приложения.

## Сборка

Требования:

- CMake 3.20 или новее.
- Компилятор с поддержкой C++20.
- MSVC или MinGW.

### CLion

Проект можно открыть в CLion как обычный CMake-проект. Текущий профиль проекта — **Release**.

При использовании bundled toolchain CLion проект собирается через MinGW и Ninja в каталоге:

```text
cmake-build-release
```

Исполняемый файл после сборки:

```text
cmake-build-release/REXPLORER.exe
```

### MinGW + Ninja

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

### MSVC x64

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Для x86-сборки Windows 10 используйте `-A Win32`.

Проект собирает автономный `REXPLORER.exe`: runtime-библиотеки компилятора линкуются статически. Для MinGW используются `-static`, `-static-libstdc++` и `-static-libgcc`; для MSVC используется статический runtime (`/MT` в Release и `/MTd` в Debug).

Исполняемый файл не требует размещать рядом DLL MinGW или устанавливать Visual C++ Redistributable. Зависимости от системных DLL Windows остаются и предоставляются самой Windows.
